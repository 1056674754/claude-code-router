## 3. 两个界面之间的关系（这也是「纳管式」的核心）

```
供应商页（一家一张卡）                     应用页（一个 app 一张卡）
┌───────────────┐                        ┌────────────────────────┐
│ CTYun         │──┐                     │ Claude Code            │
│ 模型: A B C   │  │   模型目录（引用）   │ 默认: CTYun/A          │
├───────────────┤  ├───────────────────▶ │ 槽位: Sonnet=CTYun/A   │
│ Kimi          │  │   `<供应商>/<模型>`  │ 允许: CTYun/A, Kimi/C  │
│ 模型: D E     │──┘                     └────────────────────────┘
└───────────────┘                                    │
                                                      ▼
                                          写入客户端配置（env/profile/config.toml）
                                          请求带引用 → 网关按引用找上游
```

供应商卡片管「有哪些模型、怎么显示」；应用卡片管「用哪些」。模型引用是两者之间唯一的键。
